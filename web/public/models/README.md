# Key model

`key-cnn.fp32.onnx` is stoned-mango's key and mode detector (KeyNet, 75k parameters). `key-cnn.fp32.json` is its model card: the feature settings it expects, its output layout (30 scales × 12 home notes), and its training summary.

- **Licence:** [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). This is separate from the code, which is AGPL-3.0.
- **Trained on:**
  - synthetic songs generated by `research/stoned_mango/songgen.py`, rendered with the FluidR3_GM soundfont (Frank Wen, MIT licence)
  - the **Beatport EDM Key Dataset**: Á. Faraldo (2017), annotations CC BY-SA 4.0, [doi:10.5281/zenodo.1101082](https://doi.org/10.5281/zenodo.1101082)
- **Tested on** GiantSteps Key (604 tracks, never used for training). Results are in `docs/phase2/REPORT.md`.
- **How to reproduce it:** see `docs/phase2/TRAINING-ON-WINDOWS.md` or `research/README.md`.
